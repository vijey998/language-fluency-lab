# AI-assisted practice methodology

## Goal

Build implementation fluency in C++20, C#/.NET, and Python by solving the same scheduler contracts in each language. The shared specification is the invariant; language-specific design choices are deliberately compared.

## Practice loop

1. Read `shared-spec/REQUIREMENTS.md` and the relevant assignment checkpoint.
2. Implement in `assignment/` without consulting the corresponding solution first.
3. Run the local tests and record time, syntax lookups, and failures in `PRACTICE_LOG.csv`.
4. Ask an AI assistant for a narrow hint or code review only after recording an independent attempt. Verify any generated suggestion against the specification and tests.
5. Compare with `solutions/`, then repeat the checkpoint in the other languages without line-by-line translation.

`FLUENCY_ROADMAP.md` contains the progression and exit criteria; `drills/TRANSLATION_DRILLS.md` contains cross-language exercises. The reference solutions demonstrate one implementation, not the only acceptable architecture. Practice metrics are personal observations, not benchmark evidence about language performance.
